PromptFromZero · Day 44

🎯 System 2 Attention (S2A) — a model's soft attention can't help peeking at every token, so an injected opinion or a stray irrelevant sentence quietly bends the answer (sycophancy, spurious correlation). S2A adds a deliberate first pass that regenerates the context — keeping only the facts relevant to the question and stripping the opinions and filler — then answers on that clean context. Think slow before you answer fast.

Watch an injected opinion hijack the answer — then watch a first pass scrub the context clean so the real fact wins.

An LLM's attention is soft: every token in the context gets some weight, so a confident-sounding wrong hint ("I'm pretty sure it was 2008") or an off-topic sentence can tug the answer off course — the model agrees with the opinion (sycophancy) or leans on an irrelevant detail (spurious correlation). System 2 Attention fixes this by not answering the raw context at all. First it runs a relevance pass that regenerates the context, keeping only the sentences that actually bear on the question and dropping the opinions and filler — regenerate → then answer. Everything below is real: the relevance score, the opinion detector, and both answers are computed live in JS. Flip the S2A switch and the first pass physically rewrites the context; toggle any sentence in or out, or change the injected year, and watch the raw answer chase the loudest hint while the S2A answer stays locked on the fact.

🔑 System 2 Attention = don't answer the messy context — regenerate a clean one first, then answer that. Because a transformer's attention is soft, it can never fully ignore an irrelevant or opinionated sentence sitting in the prompt; the fix isn't to ask it to ignore the junk (the tokens are still there and still attended to) but to run a deliberate first LLM pass that extracts only the question-relevant, opinion-free portion of the context. The answering pass then sees only that regenerated context, so injected hints (sycophancy) and off-topic facts (spurious correlation) simply aren't present to sway it. It costs one extra call, and it shines exactly where inputs are long, noisy, or loaded with someone's guess.

🔨 Build it yourself

    
System 2 Attention is a two-pass wrapper around ordinary LLM calls: regenerate the context to only relevant, unbiased facts → answer using only that. Here it is end to end — the naive one-shot, why "just ignore it" fails, the regeneration prompt, keeping the clean context, the answering pass, the full function, and when the extra call is worth it.

    
    
      
  1. 
        
    1
    The naive pipeline — answer the raw context (System 1)
    
        
    The default is one shot: dump the whole context plus the question into the model and take what comes out. It's fast and usually fine — but every token in that context gets attention weight, so a planted opinion or an irrelevant sentence can silently bend the answer. This is the behaviour we want to beat.
    
        
    // STEP 1 — the ordinary one-shot answer. Distractible.
const answer = await llm(`Context: """${context}"""
Question: ${question}`);
// works... until the context contains a confident wrong hint
// ("I'm pretty sure it's 2008") or off-topic noise. Then the
// model's soft attention leaks that junk into the answer.
    
      
    2. 
      
  2. 
        
    2
    Why "just ignore the irrelevant text" doesn't work
    
        
    The tempting cheap fix is to leave the messy context in place and instruct the model to disregard opinions and filler. It helps a bit, but not reliably: attention is soft, so those tokens are still in the window and still receive weight. You can't fully turn off attention with a sentence. The robust move is to physically remove the junk before the answering step — which means rebuilding the context.
    
        
    // STEP 2 — instruction-only mitigation: unreliable.
const answer = await llm(`Context: """${context}"""
Ignore any opinions or irrelevant sentences.
Question: ${question}`);
// the distractor TOKENS are still present -> attention still
// attends to them. Better than nothing, but it still gets swayed.
// Lesson: remove the text, don't just ask to ignore it.
    
      
    3. 
      
  3. 
        
    3
    S2A pass 1 — regenerate the context
    
        
    The heart of the method. Ask the model to rewrite the context, keeping only the parts that are relevant to the question and free of opinion — and to strip out anyone's stated guesses or preferences. Crucially, ask it to separate the extracted context from the question so no opinion embedded in the question leaks in either. The output is a new, clean context.
    
        
    // STEP 3 — the S2A regeneration prompt (pass 1).
const regen = await llm(`
Given the text below, extract the part of the context that is
RELEVANT to the question. Remove opinions, guesses, and any
sentence not needed to answer. Do NOT answer yet — only rewrite.

Text: """${context}"""
Question: ${question}

Return:
Relevant context: 
Question (unbiased): `);
    
      
    4. 
      
  4. 
        
    4
    Keep the regenerated context — throw the original away
    
        
    Parse pass 1 into the clean context and the unbiased question. The important discipline: from here on the original messy context no longer exists. The answering step must never see it — that's the whole point. Anything the regeneration dropped is now genuinely gone, so it cannot attend.
    
        
    // STEP 4 — split out the clean context; drop the original entirely.
const cleanContext  = parseSection(regen, "Relevant context");
const cleanQuestion = parseSection(regen, "Question (unbiased)");
// the raw `context` variable is no longer used past this line.
// only cleanContext + cleanQuestion flow forward.
    
      
    5. 
      
  5. 
        
    5
    S2A pass 2 — answer using only the clean context
    
        
    Now the ordinary answering call — but over the regenerated context, not the raw one. Because the distractors were removed in pass 1, there's nothing left for attention to be swayed by, so the answer tracks the actual fact. Same model, same one-shot answering; the only change is what it's allowed to look at.
    
        
    // STEP 5 — answer over the regenerated context (pass 2).
const answer = await llm(`Context: """${cleanContext}"""
Question: ${cleanQuestion}`);
// the opinion + filler are gone from the window -> no sycophancy,
// no spurious-correlation pull. The answer is the fact.
    
      
    6. 
      
  6. 
        
    6
    The full two-pass function
    
        
    Wrap it up: regenerate, then answer. That's the entire method — two calls where a naive pipeline used one. The regeneration is a general "clean the prompt" step, so the same wrapper works for sycophancy, long noisy documents, or math word problems padded with irrelevant numbers.
    
        
    // STEP 6 — System 2 Attention, end to end.
async function system2Attention(context, question) {
  // pass 1: deliberate — rebuild a clean context
  const regen = await llm(regenPrompt(context, question));
  const { cleanContext, cleanQuestion } = parse(regen);

  // pass 2: answer using ONLY the regenerated context
  return llm(`Context: """${cleanContext}"""
Question: ${cleanQuestion}`);
}
// 2x calls, but immune to injected opinions & irrelevant noise.
    
      
    7. 
      
  7. 
        
    7
    When to spend the extra call — and where S2A sits
    
        
    S2A (Weston & Sukhbaatar, 2023) is named for Kahneman's System 1 / System 2: the raw forward pass is fast, automatic, distractible attention; S2A adds a slow, deliberate step that decides what deserves attention. Spend the extra call when inputs are long, noisy, or opinion-laden — sycophancy-prone Q&A, retrieval dumps, user messages that smuggle in a guess. It's like RAG re-ranking but for the whole prompt, and unlike Chain-of-Thought (which reasons over the messy context) S2A cleans the context before any reasoning. Skip it for short, clean prompts where there's nothing to strip. Next: system prompts — the standing persona-and-rules turn that sets the model's role and hard constraints before the conversation starts.
    
        
    // STEP 7 — when S2A earns its extra call.
// USE for:  opinion-laden inputs (sycophancy), long/noisy context,
//           math word-problems with irrelevant numbers, RAG dumps.
// SKIP for: short clean prompts (nothing to remove), latency-critical
//           paths (2x calls), tasks where every token is relevant.
//
// System 1 = fast, automatic, distractible attention (one pass)
// System 2 = deliberate: regenerate what deserves attention, then answer

You learned System 2 Attention (S2A): because a transformer's attention is soft and can't fully ignore anything in the prompt, an injected opinion or an irrelevant sentence quietly bends the answer — sycophancy and spurious correlation. S2A beats it with a deliberate first pass that regenerates the context, keeping only the question-relevant, opinion-free facts, then answers using only that clean context — the messy original is discarded so its tokens can never attend. It's the inference-time realisation of Kahneman's slow "System 2": don't just tell the model to ignore the junk (the tokens are still there), physically rebuild a clean context. It costs one extra call and pays off wherever inputs are long, noisy, or loaded with someone's guess — proven by the demo, where the raw answer chases whatever year the hint claims while the S2A answer stays pinned to the fact. 👉 Next up — System prompts: the standing persona-and-rules turn (no user message) that sets the model's role, tone, and hard constraints before the conversation even begins.
