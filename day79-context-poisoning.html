PROMPTFROMZERO · DAY 79

🧠 Context poisoning — an agent reads a document, writes a note about it into its own context, and reads that note again next turn. The worry everybody states is that a wrong note compounds: once it is in there, everything after is downstream of the mistake. Nothing here simulates language — the engine simulates the LEDGER: 24 facts with declared truth values, twelve sources of stated reliability, a retrieval step and five context policies, over 400 enumerated runs each, so every rate is a count. 🔴 The context really does become almost entirely self-referential: by turn 60, 91.3% of the claims the agent reads are its own earlier notes, and on 5–8% of decisions it goes with a note against every source it can see that turn. 🔴 And it costs nothing measurable. Keeping every note versus keeping none moves accuracy by between −0.39 and +1.34 points across every setting tried, and the sign is usually positive. That holds at 0, 3, 5, 6, 7 and 9 bad sources in twelve. 🔴 The finding this page was built to demonstrate did not appear, and the reason is the interesting part: a note inherits the accuracy of the process that wrote it, so re-reading it is neither better nor worse than re-deriving it.

The world is invented and its truth values are declared, which is the only reason accuracy is computable at all. 24 facts, twelve sources, and a stated number of those sources that assert the opposite of the truth. Every figure below is a count over 400 runs at the settings shown; the exact percentages belong to this fixture.

Five ways to carry your own notes

1. The context does fill up with the agent's own writing

This part of the worry is exactly right, and it is worth seeing as a number. A note and a retrieved passage are the same kind of object once they are in the context — both are text the model reads — so as the run gets longer, the balance shifts.

By turn 60 with sparse retrieval, 91.3% of the claims the agent is reasoning over were written by the agent. And the self-confirmation column is a real poisoning event, counted: the agent decides against every source visible that turn because its own earlier note says otherwise.

2. And accuracy does not move

This is the part the page was built to show going the other way. Keeping every note against keeping none, at every reliability level:

The gap never exceeds 1.34 points and is usually positive — keeping notes is very slightly better. There is no reliability level at which self-generated context makes the agent worse. Turning the note's weight up so it outvotes fresh retrieval does not change it either.

3. Why, which is the part worth keeping

A note is not an independent claim. It is a record of what the same process concluded from the same kind of evidence, so it carries the accuracy of that process — no more, and no less. Re-reading it is close to re-deriving it. The context gets more self-referential without getting more wrong.

🔴 The failure mode the phrase “context poisoning” describes needs something this fixture does not have: a note that is wrong for a reason the sources would not reproduce. An error injected from outside the loop — a bad tool result, a misread date, a hallucinated identifier — is a different object from a note that merely summarises what was already there, and only the first one can compound. That distinction is the finding, and it arrived by the measurement refusing to cooperate.

What this measures and what it does not

Real: the ledger, the retrieval, the five policies, every count. Invented: the facts, the sources and their reliability, so the exact percentages are properties of this file. Worth stating plainly: the agent answers only about 4.4 of its 6 questions — on the rest, retrieval never surfaced a single claim, so it has nothing to conclude from and does not guess. Every policy leaves the same ones unanswered, so the accuracy comparison above is over identical questions. Not modelled, and each of them is where the real risk probably lives: errors that enter from outside the reasoning loop, notes that are more confident than the evidence behind them, and a decision rule that is not a majority vote. This page shows that self-reference alone is not enough to degrade anything — it does not show that context poisoning never happens.

How it works

// a note and a source are the same kind of thing once they are in context
for (const s of ctxSources) for (const a of s.asserts) claims.push({...a, fromNote: false});
for (const n of ctxNotes)                              claims.push({...n, fromNote: true});

// and the note the agent writes is derived from exactly those claims
notes.push({ fact: target, claim: decision, turn: t });

Which is the mechanism and the answer at once: the note is a function of the sources, so it inherits their reliability rather than adding an error of its own.

Self-check

Runs on load. Several are controls — including the one that matters most here: with no unreliable sources the agent is exactly 100% accurate, so the measurement can detect a difference when there is one to detect.
